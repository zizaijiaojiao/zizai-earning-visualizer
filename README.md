# 自在赚钱可视化

这是一个给单人使用的静态网页，不需要后端。将 `index.html`、`styles.css`、`script.js`、`coin-illustration.svg` 和 `favicon.svg` 放在腾讯云服务器的同一个网站目录，通过同一域名访问即可。直接打开 `index.html` 可预览；若要可靠保存记录，请通过网站地址访问。

## 使用说明

1. 打开右上角「设置」，填写他的昵称、首页留言、你的落款，以及两站心愿的名称和金额。第二站默认只是示例，请改成你们真正想要的项目。
2. 确认工资、工作时间、开始日期和汇率。初始汇率 `0.9` 仅供演示，并非实时汇率。正常工资默认每天 1,100 港币，计薪时段为 9:00–12:00 和 13:00–18:00；加班开启后，18:00–20:00 再均匀累计 225 港币。
3. 可在日历补记加班、请假和额外上班。整数奖励默认为当天赚到 300、600、900、1100 港币时提醒一次，金额与文案可在设置中修改。
4. 买到第一站的手机后，点击「手机买到啦，开启下一站」并确认。第二站从确认那一刻的 ¥0 开始，第一站超出的金额不结转；累计总收入仍保留。第一站的名称、金额、购买时间和当时累计金额会归档。
5. 首次打开时会立即保存累计开始日期。之后每天打开，网页都会从开始日期重新计算过去的工作日工资，并加上当天实时收入；日历里的加班、请假和额外上班记录也会保留。换设备或域名时，先导出备份，再在新页面导入。网页可读取上一版的备份和同域名的上一版浏览器记录。

金币雨仅在计薪时段持续播放；页面隐藏或系统设置减少动态效果时会暂停。所有工资金额和目标进度均为估算，不等于实际到账或存款。网页不会主动上传这些记录。
